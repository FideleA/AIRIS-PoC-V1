# AIRIS canonical charging-location schema

## Scope and row granularity

The canonical dataset contains one row per physical charging location. An EVSE or connector must not create a separate location row; EVSE and connector detail is represented by aggregate counts. Provider-native source data remains unchanged in `data/raw/charging/`, while a reproducible processing step maps it to this canonical contract.

All 21 columns must be present. “Required” below means every retained row must contain a usable value. Optional columns must use an empty CSV value (read as null), never placeholder strings such as `N/A`, `unknown`, `-`, or `0` unless zero is the true value.

## Fields

| Field | Type | Status and permitted missing value | Meaning and normalisation | Source provenance |
|---|---|---|---|---|
| `station_id` | string | Required; never missing | Stable AIRIS identifier generated by the algorithm below. Trim surrounding whitespace. | Derived by AIRIS from provider identity fields. |
| `source_record_id` | string | Optional; null only when the provider supplies no stable record ID | Preserve the provider identifier as text, including leading zeros; trim surrounding whitespace. | Provider record. |
| `station_name` | string | Required; never blank | Human-readable physical-location name. Unicode-normalise and collapse repeated whitespace without inventing operator claims. | Provider name, or a documented deterministic fallback. |
| `address` | string | Optional; null permitted | Single-line address; trim and collapse whitespace. Do not append credentials or private contact details. | Provider address fields. |
| `postcode` | string | Optional; null permitted | Uppercase UK postcode with internal spacing normalised where present. | Provider address fields or verified address correlation. |
| `latitude` | float | Required; never missing | WGS84 decimal degrees in `[-90, 90]`; do not store projected coordinates. | Provider coordinates or a documented verified correction. |
| `longitude` | float | Required; never missing | WGS84 decimal degrees in `[-180, 180]`; do not store projected coordinates. | Provider coordinates or a documented verified correction. |
| `operator_name` | string | Optional; null permitted | Current operator name where explicitly supplied; trim whitespace and retain authoritative spelling. | Provider or operator source. |
| `data_provider` | string | Required; never blank | Stable name for the organisation/dataset supplying the record; normalise only whitespace and case for ID generation. | Dataset-level provenance. |
| `operational_status` | string | Optional; null permitted | Map source values, where supported, to `operational`, `temporarily_unavailable`, `planned`, `decommissioned`, or `unknown`; document the mapping. | Provider status field. |

| `usage_cost` | string | Optional; null permitted | Concise provider-supplied tariff/access text; do not calculate or imply a current price. | Provider tariff text. |
| `source_url` | string | Optional; null permitted | Public dataset or record URL without query credentials, user information, tokens, or secrets. Prefer HTTPS. | Provider publication endpoint. |
| `source_last_updated` | ISO 8601 date/datetime string | Optional; null permitted | Preserve provider update time in ISO 8601; include timezone when time is present. | Provider record/dataset timestamp. |

| `attribution` | string | Optional only until verified; null permitted | Required attribution wording, reproduced accurately. | Provider licence/publication metadata. |
| `verification_status` | string enum | Required; never missing | One of the controlled values below. | AIRIS review workflow. |
| `verification_notes` | string | Optional; null permitted | Concise evidence, discrepancy, exclusion, or correlation note; no secrets or personal data. | AIRIS review workflow and cited public evidence. |

## Stable `station_id` generation

Python `hash()` must never be used because its result is not stable across interpreter runs.

1. Unicode-normalise provider and identity text with NFKC, trim it, case-fold it, and collapse repeated whitespace.
2. Prefer the identity string `provider=<data_provider>|record=<source_record_id>` when a stable source record ID exists.
3. Otherwise use `provider=<data_provider>|name=<station_name>|latitude=<latitude>|longitude=<longitude>`, with WGS84 coordinates rounded to five decimal places.
4. Compute SHA-256 over the UTF-8 identity string.
5. Set `station_id` to `airis_` followed by the first 20 lowercase hexadecimal characters.

The provider record ID is the preferred identity because names and coordinates can change. Fallback-ID changes and possible duplicate physical locations must be reviewed rather than silently merged. The full source identity fields are retained so an ID can be reproduced and audited.

## Verification status

| Value | Meaning |
|---|---|
| `unreviewed` | Imported and schema-valid, but not independently checked. |
| `coordinates_checked` | Coordinates were checked against suitable public geographic evidence. |
| `operator_source_checked` | The record was checked against an authoritative operator source. |
| `council_correlated` | The location was correlated with an appropriate council-published record. |
| `excluded` | Retained for audit but excluded from AIRIS use; the reason belongs in `verification_notes`. |

Statuses describe the strongest completed verification route, not a cumulative workflow score.

## AIRIS scoring compatibility

This schema represents charging locations before flood and deprivation enrichment. It intentionally retains the existing application keys `station_id`, `station_name`, `latitude`, and `longitude`. A later dashboard-ready processing step must join or calculate `flood_score` and `deprivation_score` on the existing 0–100 scales and supply the current `source` field. The charging schema does not change scoring weights, thresholds, or calculations.

Only non-`excluded` records should progress into a dashboard-ready dataset. Sample mode continues to use the unchanged `data/stations.csv` until an explicit mode-selection change is approved.
