# Deprivation data notes

No external deprivation dataset has been registered or downloaded yet.

Before adding a source-register entry, verify the authoritative provider, source URL, publication date, licence, attribution requirements, geographic coverage, indicator definition, reference period, coordinate reference system, update frequency, and known limitations.

Document all future extraction and processing steps here. Raw source files belong under `data/raw/deprivation/`; dashboard-ready outputs belong under `data/processed/`.
