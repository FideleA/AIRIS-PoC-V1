# Flood data notes

No external flood dataset has been registered or downloaded yet.

Before adding a source-register entry, verify the authoritative provider, source URL, publication date, licence, attribution requirements, geographic coverage, flood type, resolution, coordinate reference system, update frequency, and known limitations.

Document all future extraction and processing steps here. Raw source files belong under `data/raw/flood/`; dashboard-ready outputs belong under `data/processed/`.
